## 🎯 แนวคิดของระบบ

ระบบนี้ถูกออกแบบมาเพื่อใช้เป็น **ลิงก์กลาง (Gateway)** สำหรับ QR Code
โดยมีแนวคิดหลักคือ

> **QR Code ใช้ URL เดิมตลอด**
> **เอกสารปลายทางสามารถเปลี่ยนได้จากฝั่ง Server**

เหมาะสำหรับเอกสารของหน่วยงาน เช่น

* รายงานประจำปี
* หนังสือราชการ
* เอกสารเผยแพร่ระยะยาว

---

## 🔗 การนำไปใช้งาน

นำ URL นี้ไปใช้สร้าง QR Code

```
https://apps4.coop.ku.ac.th/qr/?job=annual
```

เมื่อมีการสแกน QR Code:

* ระบบจะประมวลผลจากฝั่ง Server
* ผู้ใช้จะถูกนำไปยังเอกสารปลายทางโดยอัตโนมัติ

---

## 🗂️ การจัดการเอกสาร

ระบบใช้ไฟล์ **`data.json`** เป็นแหล่งข้อมูลหลัก
การเปลี่ยนเอกสารทำได้โดย **แก้ไขไฟล์นี้เพียงไฟล์เดียว**

> ❌ ไม่ต้องแก้โค้ด PHP
> ✅ ไม่ต้องสร้าง QR Code ใหม่

---

### 📄 กรณียังไม่มีไฟล์เอกสาร

```json
{
  "annual": {
    "title": "หนังสือรายงานกิจการ ประจำปี 2568",
    "note": "ประชุมใหญ่ วันที่ 28 มกราคม 2569"
  }
}
```

ระบบจะแสดงหน้า **Coming Soon** เพื่อแจ้งสถานะเอกสาร

---

### 📄 กรณีมีไฟล์เอกสารแล้ว

```json
{
  "annual": {
    "title": "หนังสือรายงานกิจการ ประจำปี 2568",
    "latest": "files/รายงานกิจการ2568-final.pdf"
  }
}
```

หรือใช้ไฟล์จากภายนอก

```json
{
  "annual": {
    "title": "หนังสือรายงานกิจการ ประจำปี 2568",
    "latest": "https://example.com/annual2568.pdf"
  }
}
```

เมื่อเพิ่ม `latest`

* หน้า Coming Soon จะไม่ถูกแสดง
* QR Code เดิมจะเปิดเอกสารทันที

---

## ✅ สรุป

* QR Code ใช้งานได้ระยะยาว
* เปลี่ยนเอกสารภายหลังได้
* ดูแลรักษาง่าย เหมาะกับงานหน่วยงาน

> **QR ไม่ต้องเปลี่ยน**
> **เปลี่ยนแค่ข้อมูลใน `data.json`**
