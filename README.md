# 📌 งานสำหรับการเจน QR Code (QR Management)

โฟลเดอร์นี้ใช้สำหรับ **ระบบกลางในการสร้างและจัดการ QR Code**  
โดยออกแบบให้ QR Code **สามารถเปลี่ยนปลายทางภายหลังได้**  
โดยไม่ต้องสร้าง QR ใหม่

---

## 🎯 วัตถุประสงค์
- ใช้เป็น **ศูนย์กลาง (entry point)** สำหรับ QR Code
- รองรับการใช้งานทั้ง
  - QR เดียว หลายงาน
  - แยก QR อันละงาน
- เปลี่ยนไฟล์ / ลิงก์ปลายทางได้ในอนาคต
- เก็บสถิติการสแกน (log)

---

## 📂 โครงสร้างโฟลเดอร์

```text
/qr/
 ├─ index.php        # จุดเข้า (QR Code ชี้มาที่ไฟล์นี้)
 ├─ config.php       # config กลาง สำหรับทุกงาน
 ├─ download.php     # จัดการดาวน์โหลด + ตั้งชื่อไฟล์
 ├─ log.php          # เขียน log การสแกน
 ├─ logs/
 │   └─ scan.log     # ไฟล์เก็บสถิติการสแกน
 ├─ mode/
 │   ├─ auto.php     # โหมดเปิดเอกสารอัตโนมัติ (โหมดหลัก)
 │   ├─ select.php   # โหมดให้ผู้ใช้เลือกเอกสาร
 │   └─ schedule.php # โหมดเปลี่ยนเอกสารตามเวลา
 └─ files/
     └─ annual_latest.pdf  # ไฟล์ local (ถ้ามี)
